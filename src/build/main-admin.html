Textos (todas las idiomas)

JSON: claves por idioma (es, en, nl, fr, de) y dentro cada clave i18n → texto. Solo incluye las claves que quieras sustituir. Ejemplo: {"es":{"hero.headline":"Nuevo título"}}

Tras guardar, recarga la página pública para ver los cambios (o espera unos segundos por la caché).

Galería Obra — añadir / quitar

Añadir piezas: array add con objetos id (número único, p. ej. 10001), image (URL), category (bordados, dibujos, instalacion, plasticina, telar, volumen), url (Etsy), name, price, currency.

Quitar piezas del listado base: en removeIds pon los id numéricos de la galería estática que quieras ocultar.

Subir imagen

PNG, JPG, WebP o GIF (máx. ~12 MB). Copia la URL resultante y úsala en el JSON de galería.
